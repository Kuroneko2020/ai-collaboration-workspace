# 首版模板设计与验证边界

## 定位

当前版本 `0.1.0-preview.3`：可独立解压的个人 AI 协作区起步模板。首版 preview.1 的手动默认已按用户试用反馈调整为普通自动记忆默认；旧版记录与候选包保留，不改写历史。研发项目与实际使用模板分开，首版面向 Windows、本地可写目录、Python 3.11+ 和具备文件读写及命令执行能力的 Agent。

不安装模型、客户端、插件、MCP、Hook 或后台服务，不修改用户级配置，不自动联网或上传，也不宣称已经验证所有客户端的自动加载。

## 内容分工

- `模板/个人AI协作区/` 是干净源码：规则、默认协作底色、空记忆入口、管理工具及最简主题导航。
- 根目录仅保留 `AGENTS.md`、`README.md`、`.gitignore`、`中枢/` 和 `待整理/`；脚本与模板元数据均归中枢。
- 管理入口为 `中枢/工具/工作区管理/工作区管理.py`，使用脚本自身 `parents[3]` 定位工作区，不依赖当前进程目录。模板信息在 `中枢/模板/模板信息.json`，出厂哈希基线由构建器生成在包内 `中枢/模板/出厂文件清单.json`。
- `工具/打包.py` 依据明确文件清单验证并生成 ZIP、包内 SHA-256 清单及外部校验文件，不从个人工作区动态收集文件。
- `测试/` 保存工具回归测试与模板端到端测试；运行样本和详细日志归本地隔离目录。
- `发行/` 保存本次实际生成的候选包；默认不纳入 Git，不等同 GitHub Release。

## 初始化合同

`中枢/工具/工作区管理/工作区管理.py init` 只在模板自身目录中建立新身份及必要机械状态，不覆盖既有用户数据。不从当前 cwd 推断其他目标，不导入原工作区标识或个人记忆。

- 生成合法、完整的六字段记忆配置以及带版本、工作区身份、记忆模式的启用状态。
- 首次启用前说明默认普通自动记忆的范围；初始化从模板信息读取默认 `auto`，只保存当前相关交流与已授权材料中有明确后续用途的普通协作记忆，不要求每条确认。启用依据如实记为采用模板已说明的默认策略，不伪造逐项同意或继承作者旧授权。
- 首次可用 `init --memory-mode manual` 关闭，启用后可用 `configure --memory-mode manual` 关闭。已有 manual 副本明确切回 auto 时使用 `configure --memory-mode auto --consent-source ...`。重复 init 不改变已选模式。
- 未启用 status 只报告 `default_memory_mode`，实际 `memory_mode` 为 null，不将模板默认说成已启用。缺失或冲突状态仍拒绝自动写入。
- 重复初始化不轮换身份，不重置模式或个人记忆；异常、部分初始化、非法配置与身份冲突明确报错，不以重建覆盖修复。
- 已有条目、索引、事务或异常链接而没有完整启用状态时，不视作干净新工作区。
- `status` 不创建状态、运行锁或目录；`init` 完成后索引可由既有记忆 CLI 重建。

工作区管理工具不会执行 Git、修改全局配置、安装环境或为用户自动授权。启用状态属于协作约定，不是阻止任意编辑器直接操作文件的权限系统。

## 记忆工具

采用来源工具的稳定布局与标准库实现，保持 root 求解、校验、范围过滤、版本/SHA 冲突检查、系统锁和可恢复事务。个人条目、配置、索引、锁、事务及凭据一概不从来源复制。

分发的源码清单与来源校验值由本地提取记录保存。个人化规则负责“是否值得记、来源是否充分和场景是否适用”；工具不训练模型、不自动推断用户人格。

## 验证要求

- 空库初始化、配置与启用状态一致、重复初始化、异常链接/部分状态拒绝、模式切换及错误参数不落盘。
- 新目录解压、首次写入、另一个 CLI 进程检索、修正后再检索、派生重建、整体搬迁后默认 root 与工作区身份保持有效。
- 两个新副本独立初始化后身份不同，均不预装个人记忆。
- 明确文件清单、相对链接、常见秘密与作者环境标记检查；构建遇额外文件、链接或运行数据时拒绝纳入，而不是猜测过滤。
- 工具回归测试在隔离根运行；Windows 夹具在其他系统明确跳过，不把未执行环境称为验证通过。

CLI 子进程验证不等于独立模型新会话行为验收。本首版交付不以脚本测试替代真实客户端自动加载和用户使用体验验证，也不声明断电、网络盘或同步盘安全保证。

## Git 与发布

在工作分支开发，保留当前已上传 `main` 的状态；本轮制作不自动提交、推送或创建 GitHub Release。许可证未选择，不添加未经用户决定的开源许可。生成包用于当前授权范围的预览交付，进一步公开发行按明确要求办理。
