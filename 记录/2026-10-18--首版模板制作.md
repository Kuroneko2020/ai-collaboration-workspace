# 2026-10-18：首版模板制作

## 目标与授权

用户在可行性评估后明确要求直接制作首版模板。本次制作 `0.1.0-preview.1`，在独立研发项目内提炼通用规则、复制工具副本、开发初始化与打包、运行隔离测试并交付本地候选 ZIP。

本轮未授权新的 Git 提交、远端推送或 GitHub Release；不修改生产中枢、个人记忆、客户端配置，也不安装外部能力。开发分支为 `feat/workspace-template-v0.1`，起点工作树干净，公开 `main` 保持此前状态。

## 来源与变更对象

- 已有工作区规则提供管理方法；新模板不复制个人资料、项目列表、记忆条目、原授权或固定路径。
- 已有记忆 CLI 以明确源码清单提取，保留算法与数据合同；仅模板副本中的作者环境注释作通用化，原工具不变。
- 通用说明与初始化器、构建工具、端到端测试是本次新建成果。
- 设计合同见[首版模板设计](../设计/首版模板.md)；构建和复测命令见[工具说明](../工具/README.md)。

## 首版约定

- 独立工作区、空记忆、新工作区标识、默认手动记忆。
- 普通自动记忆需要接收者明确启用；作者的授权不能继承。
- 不预建大量主题，不自动后台运行，不安装插件或改全局配置。
- 初始化不覆盖既有状态；异常、部分初始化、身份冲突或链接明确拒绝。
- 打包严格使用文件清单，遇额外文件、运行数据或个人环境标记即失败。
- 首版运行验证限定 Windows、本地可写目录及已安装 Python。Python 3.11 语法兼容检查与本机具体版本执行分别报告。

## 本轮实际验证

执行环境：Windows、Python 3.14.0，使用标准库和临时隔离根，禁写源码字节缓存。全部模板 Python 源码通过 Python 3.11 语法解析，但未在 3.11 解释器实跑。

- 工具最初 63 项回归：62 通过、1 跳过、0 失败/错误。增加四项模板合同后最终 67 项：66 通过、1 跳过、0 失败/错误，用时 71.197 秒。跳过为创建文件符号链接缺少 Windows 特权；目录 junction 测试实际通过。
- 模板端到端最终 28 项全部通过，用时 12.445 秒；覆盖空库、只读状态检查、重复初始化、独立身份、模式切换及授权来源、冲突保护、写入与纠正、索引、搬迁、构建及 ZIP 解压。
- 合计最终两套测试 95 项，94 通过、1 权限跳过，不能称“95 项全部通过”。
- 34 个模板源码文件严格符合发行清单，常见秘密与作者环境标记扫描、相对链接、生成标记及空记忆检查通过；没有来源配置、个人条目、缓存、运行锁或事务。
- 实际交付 ZIP 的 35 个条目逐项核验，34 个原文件大小与 SHA-256 均符合包内清单，ZIP CRC 与外部 SHA-256 正确。
- 对该实际 ZIP 解压所得的新目录运行 `status`、`init`、重复 `init`、空库 `context`、`reindex`、新鲜度检查、`validate`、`doctor` 均成功，初始记忆为零、默认 manual、重复身份不变，doctor 无 warning/error。干净模板源码仍无运行配置或启用状态。

测试日志及结构化证据仅保留在项目 `本地/模板验证/` 和 `本地/工具提取验证/`，不纳入分发包或公开仓库。工具来源双哈希清单也保留在本地。该次端到端验证用独立 CLI 进程，不是模型新会话行为验收。

## 发现与修复

- 初测 Windows junction 夹具因系统输出编码与 UTF-8 假设冲突报错，改为按字节收集系统命令输出；失败日志保留。
- 夹具修正后发现初始化器用 `stat()` 跟随 junction，导致管理目录拒绝检查失效。改为 `lstat()`，并为初始化器和构建器添加回归。
- 只读定向审查另外指出根或祖先联接漏检、引用式/本地 URI 文档链接绕过，以及空目录链接不随 ZIP 交付三个问题。
- 修复为保留未解析的初始化入口并逐级检查祖先，构建来源同样检查祖先；文档扫描加入引用定义、HTML 与自动链接，对外只接受 HTTP/HTTPS；本地目标必须对应实际归档文件或其目录。
- 新增五项对应测试后，全量 28 项复测通过。审查结果与主会话验证分别报告，不声称审查 Agent 独立实跑。
