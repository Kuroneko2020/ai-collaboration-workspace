# 制作与验证工具

在研发项目根目录运行，使用已安装的 Python，不安装第三方包。Windows 示例使用 `py -3`；实际执行验证的 Python 版本见制作记录。

## 只检查干净模板

```powershell
py -3 -B -X utf8 工具/打包.py --check --json
```

检查明确清单、常见秘密及用户主目录路径、Python 3.11 语法、相对链接和空记忆生成区。遇额外文件、运行状态或链接时拒绝构建，不从当前个人工作区收集文件。

## 生成候选压缩包

```powershell
py -3 -B -X utf8 工具/打包.py --json
```

默认在 `发行/` 新建带版本和 UTC 构建时间的 ZIP 及 `.zip.sha256` 校验文件，不覆盖已有包。包内顶级目录为 `个人AI协作区`，包含逐文件 SHA-256 基线 `中枢/模板/出厂文件清单.json`。内容相同的干净源码会生成相同的 ZIP 字节，外部文件名不同。

`工具/发行清单.json` 是纳入权威；添加新模板文件时先检查来源、隐私与许可，再修改清单。构建完成不等于客户端行为或长期使用已经验收。

## 隔离验证

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
py -3 -B -X utf8 -m unittest discover -s 测试/记忆工具 -v
py -3 -B -X utf8 -m unittest discover -s 测试 -p test_template.py -v
```

工具回归与模板端到端测试只操作临时根，不初始化 `模板/个人AI协作区/` 源码。模板测试覆盖空库、身份、授权模式、冲突保护、写入/纠正、搬迁、包解压和打包拒绝边界。详细执行结果见项目制作记录，不把测试文件存在当成已执行。

## 不做的事

这些工具不安装环境、不联网、不改客户端或用户级配置、不自动 Git 提交或推送、不发布 GitHub Release、不扫描个人主题，也不替使用者同意自动记忆。不要在干净模板源码中日常使用；先解压或复制独立工作区。
