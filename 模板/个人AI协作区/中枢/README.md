# 中枢

这里保存多个 Agent 可以共同读取的规则、导航、协作底色和精简背景。具体项目的输入、成果、现状与记录留在各自主题，不把中枢做成个人档案全集或跨主题流水账。

## 按需要找入口

| 需要 | 入口 |
| --- | --- |
| 开始会话、确认工作区与启用条件 | [根 AGENTS](../AGENTS.md)、[根 README](../README.md) |
| 文件、代码、数据、配置或归档操作 | [工作区维护指南](工作区维护指南.md) |
| 找主题和资料 | [主题路由表](主题路由表.md) |
| 了解共同交流底色 | [灵魂](灵魂/灵魂.md)、[修改规则](灵魂/管理规则.md) |
| 读取或维护有来源的背景 | [记忆入口](记忆/记忆.md)、[记忆管理规则](记忆/管理规则.md) |
| 数据字段、检索与实际命令 | [格式规范](记忆/格式规范.md)、[记忆工具说明](工具/记忆工具/README.md) |

这些入口是导航，不意味着客户端会自动跟随链接加载全部内容。

## 运行状态在哪里

本模板版本为 **0.1.0-preview.3**，初始没有运行身份、个人条目、种子或作者项目。默认普通自动记忆策略在根 README 与 AGENTS 中于首次启用前说明，接收者选择采用该策略后独立启用，不继承作者旧授权。是否已启用不在 README 中手工登记：在工作区根运行 `py -3 -X utf8 中枢/工具/工作区管理/工作区管理.py status` 只读核对；尚未初始化时为 `not_initialized`、`memory_mode=null`、`default_memory_mode=auto`，不是已经开启。

- `中枢/启用状态.json`：初始化生成的独立工作区身份、模板版本、记忆模式等运行状态。
- `中枢/记忆/配置.json`：初始化生成的六字段工具配置；字段合同见格式规范。
- 两个运行文件均不随模板源码预装，启用后必须保留，并非用完可删的临时文件。重复初始化保留既有身份和模式，不重写文件；缺失、损坏或冲突时停止公共记忆写入并核对，不用默认 auto 或手改 JSON 强行接管。

缺 Python、写权限或工具时，按根 AGENTS 与记忆入口降级，不将“文件可读”说成“已初始化或工具可用”。程序检查也不等于客户端自动加载或用户使用验收。

## 日常协作

用户采用已告知的默认策略完成首次启用后，auto 在[记忆管理规则](记忆/管理规则.md)的普通范围内持续维护，无需第二轮启用或逐条确认；不全盘扫描、不记每轮日志，不自动保存凭据、明显敏感个人信息、第三方隐私或企业隐私。首次可用 `init --memory-mode manual` 关闭，初始化后用 `configure --memory-mode manual`；manual 副本明确改回 auto 才按根 README 提供真实简短来源。记忆模式、灵魂与操作授权相互独立，不自动 Git、外发或改长期灵魂。

记忆的语义判断由主会话负责，公共写入经 CLI 完成。正常查询也需要可写运行锁，不适用于只读介质；工具不可用时人工按需读取，不宣称并发保护已工作。自动维护不是后台服务，也不是每轮聊天的活动日志。

中枢治理变更的记录放在对应具体事项中；普通记忆变更使用 `中枢/记录/记忆变更/` 的 CLI 凭据。需要建立其他治理记录时按实质任务建立，不预造空日志，不复制敏感正文。这里不另维护与项目重复的版本或验收清单，不自动提交 Git 或外发。
