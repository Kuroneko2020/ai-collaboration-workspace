# 记忆

这里是跨 Agent 的普通记忆短入口。有来源的认识保存在 `中枢/记忆/条目/` 的当前权威文件中；本文件不手工复制条目结论。模板初始为空，不带个人信息、种子条目或作者的持续维护授权。

## 按当前任务读取

1. 先执行[根 AGENTS](../../AGENTS.md)的启用检查，读取[灵魂](../灵魂/灵魂.md)与本文件，再判断当前任务的目录、场景和关键词。首次启用默认 auto；已启用副本以实际模式为准，manual 也不禁止正常查询。
2. 已启用、Python 3.11+ 与工具可用时，在工作区根按实际任务运行，例如：

   ```powershell
   py -3 -X utf8 中枢/工具/记忆工具/memory.py context --cwd . --scene engineering --query "相关关键词"
   ```

   `--cwd` 应表达任务实际所在目录，场景和关键词按需要选择。场景不明时不硬套条件性偏好；`context` 只取适用核心条目与相关命中，不代表列出全部记忆。
3. 用户提到“上次”“继续”“我的习惯”或项目背景时，先 `search` 相关关键词，再去主题权威来源核对。空结果不等于可以猜测或建立个人条目。
4. 所有正常查询也会使用**可写运行锁**，不是只读介质工具。查询不等于确认条目仍正确，不因读取更新个人事实、revision 或验证日期；不把 `context`、`search` 或 `reindex` 称作严格只读命令。
5. 已在当前上下文的内容不每轮重读；切换主题、出现纠正或怀疑更新时定点刷新。执行型子 Agent 只接收分工所需背景。

## 写入与模式

首次启用默认 **auto**：用户采用根 README 与 AGENTS 已告知的默认策略后，主会话可持续维护当前相关交流及已授权相关材料中普通、稳定、有明确后续用途的信息，无需第二轮启用或逐条确认；不继承作者旧授权。首次可选 manual，初始化后可关闭；manual 副本明确改回 auto 才用带真实来源的 `configure`。未初始化或状态缺失、损坏、冲突时不写记忆，不用默认 auto 绕过异常。详细授权、隐私边界、候选、冲突与停用政策只维护在[管理规则](管理规则.md)。新增、纠正及停用经 CLI 的 `add` / `update` / `apply`，不直接手改条目。

初始化、锁文件与 `reindex` 等派生机械文件维护不等于保存个人信息；原模板的下方生成区保持为空，启用后可由工具重建空提示或链接。

## 降级读取

未启用、缺 Python、工具不可用、无写权限或锁失败时，说明具体限制，不宣称自动检索或并发保护已工作。按需人工检查本入口与已知相关条目，核对 metadata 中的状态、范围、有效日期、复核日期与来源；仅将 active、适用且在有效区间内的认识作为当前背景，候选与已停用条目不作为现状。

此时不直接写公共条目、不手改运行配置来消除错误。用户要求保存的内容可在当前会话列为待处理建议，工具恢复后再经 CLI 办理；未获同意不为降级另建含个人信息的临时文件。普通任务继续安全可做部分。

## 唯一详细入口

- [管理规则](管理规则.md)：记什么、何时读写、manual/auto、来源、澄清、冲突和停用。
- [格式规范](格式规范.md)：条目字段、状态、范围、时间与六字段配置合同。
- [记忆工具说明](../工具/记忆工具/README.md)：真实命令、退出码、锁、事务、检查与恢复方式。
- [客户端接入](../接入/客户端接入.md)：显式启动和验证边界。

`中枢/记忆/配置.json` 由工作区管理程序执行初始化时生成，不在模板源码中预装；不要为方便查询导入作者的配置、条目或授权。
