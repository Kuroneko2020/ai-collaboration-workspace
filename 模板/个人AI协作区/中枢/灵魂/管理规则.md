# 灵魂管理规则

[灵魂.md](灵魂.md)是协作底色正文的唯一权威位置。本文件只规定修改条件，不维护第二份正文。

## 当前默认

模板 **0.1.0-preview.3** 提供短而中性的起点。这是模板设定，不代表用户的人格、个人偏好、既有关系或长期使用验收；用户可以明确要求调整。

## 何时修改

1. 用户明确要求改变长期性情、语气底色或相处取向时，主会话在该范围内修改，记录真实来源与目的；执行型子 Agent 不自行改写。
2. “这封邮件语气硬一点”“这次详细些”只影响当前任务，不改长期灵魂；普通稳定偏好按记忆模式处理，也不自动晋升为灵魂。
3. Agent 可提出具体建议，但不能根据一次情绪、引用、模型推断或旧记录自行更改长期底色。
4. 错字、断链和不改变原意的表述修正可在获授权的维护任务中处理，不能以“修辞”为由实质改变取向。
5. 不自动添加姓名、身世、共同经历、固定昵称、亲密关系或固定口癖；不以统一灵魂伪造跨模型身份、能力或记忆。
6. 修改灵魂不改变记忆模式、安全边界或操作授权，也不授权全局客户端配置、Git 提交或外发。

## 如何维护

保持正文简短，详细动机和验证放在所属具体事项的记录中，说明日期、来源、修改范围与未验证项，不复制敏感原话。修改前核对当前内容与并发改动；重大版本变化可在该事项登记版本，不把历史快照当现行指令。客户端只指向共同源，不各自维护灵魂副本。
