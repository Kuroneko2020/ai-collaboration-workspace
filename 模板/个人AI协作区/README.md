# 个人 AI 协作区

**版本：0.1.0-preview.3。** 这是可被选作日常使用位置的实际工作区模板，不是只供阅读的说明包。它用普通文件保存协作规则、可调整的交流底色、有来源的记忆与项目入口，不训练模型，也不是独立运行的 Agent 应用。

首版验证目标为 **Windows 本地可写目录、Python 3.11+ 标准库，以及能读写文件和执行命令的 Agent**。不承诺其他操作系统、网络盘、只读介质或任何特定客户端的自动接入。

本版在 Windows + Python 3.14 下完成 34 项模板端到端测试，覆盖精简布局、管理工具自定位、初始化、模式切换、记忆生命周期及打包解压；Python 3.11 只做语法检查，未在 3.11 解释器实跑。客户端 GUI 的独立新会话接入与用户使用验收尚未完成，不能以程序检查通过代替。

## 从这里开始

1. 把分发包解压到自己选择的本地目录。选择包含本 README、`AGENTS.md`、`.gitignore`、`中枢/` 和 `待整理/` 的文件夹作为实际工作区；**选择解压出的工作区，而不是研发仓库或模板源码目录**。不要为试用覆盖已有个人资料或生产工作区。
2. 首次启用前请知悉：**默认 auto，持续自动维护普通记忆**，只保存当前相关交流和已授权相关材料中普通、稳定、有明确后续用途的信息；不全盘扫描、不记每轮日志，不自动保存凭据、明显敏感个人信息、第三方隐私或企业隐私，不自动 Git、外发或改长期灵魂。你选择按此默认策略启用即可，范围内无需逐条确认，也不必再同意一次 auto；这不继承作者旧授权。
3. 用有文件与命令能力的 Agent 打开该目录。Python 3.11+ 已安装时，可以直接说“请按根 AGENTS 检查并以默认策略启用这个工作区”。模板不代装 Python 或依赖，不修改全局配置。若 Agent 没有自动读取入口，复制[会话启动指令](中枢/接入/会话启动指令.txt)到当前会话；其相对路径须指向上一步实际工作区。
4. Agent 可执行下面的初始化，你也可以在工作区根运行。`init` 按 `中枢/模板/模板信息.json` 的 `default_memory_mode` 建立独立身份、空记忆和默认 auto，并记录采用已说明模板策略的真实依据，不伪造逐项确认。首次希望关闭自动维护，请改用下一节的 manual 命令。

```powershell
py -3 -X utf8 中枢/工具/工作区管理/工作区管理.py init
py -3 -X utf8 中枢/工具/工作区管理/工作区管理.py status
```

`status` 是只读检查：未初始化报告 `not_initialized`、`memory_mode=null` 和 `default_memory_mode=auto`，不是已经开启。重复 `init` 保留既有身份和模式，即使带模式参数也不切换；遇到缺失一份运行文件、损坏或冲突时拒绝覆盖并停止公共记忆写入，不用模板默认绕过异常。缺 Python、不可写或程序不可用时，Agent 应明确降级，继续安全可做的普通任务，不把失败说成已启用。

## 记忆由你选择

首次不采用默认自动维护，用以下命令代替上面的 `init`：

```powershell
py -3 -X utf8 中枢/工具/工作区管理/工作区管理.py init --memory-mode manual
```

初始化后关闭自动维护：

```powershell
py -3 -X utf8 中枢/工具/工作区管理/工作区管理.py configure --memory-mode manual
```

manual 下不自动新增、更新或创建候选；你明确说“记住这件事”“纠正已存的这条”时，仍可按范围经 CLI 保存。关闭不删除已有记忆，也不禁止正常查询。初始化、运行锁与索引重建等机械维护不等于记录个人信息。

**仅已用 manual 的副本明确改回 auto 时**，才执行下列命令；将来源占位文字替换为你本次真实启用决定的简短说明，不复制敏感正文。新用户采用默认 auto 不需要额外执行。

```powershell
py -3 -X utf8 中枢/工具/工作区管理/工作区管理.py configure --memory-mode auto --consent-source "用户本次明确启用的简短来源"
```

`init`、`status`、`configure` 可加 `--json` 获取机器可读结果。完整政策见[记忆管理规则](中枢/记忆/管理规则.md)，用户不必手工编辑数据格式。

## 根目录用途与生命周期

根目录只保留下列入口与目录，脚本统一收在中枢，不保留旧根脚本壳子。

| 文件或目录 | 用途与是否保留 |
| --- | --- |
| [AGENTS.md](AGENTS.md) | Agent 指令入口：启动、按需读取和最低边界；持续保留 |
| 本 README | 给用户的使用说明、模式选择和文件用途；持续保留 |
| `.gitignore` | 覆盖整个工作区的 Git 忽略规则，保留在根以维持现有作用范围；降低私人内容被误跟踪的机会，不是保密措施，也不清除已跟踪内容；保留 |
| [中枢/](中枢/README.md) | 共同规则、灵魂、记忆、管理工具、模板元数据和接入入口；[主题路由表](中枢/主题路由表.md)是唯一人工主题总导航，不放全部个人档案 |
| [待整理/](待整理/README.md) | 暂时未定归属的新事项，不是自动聊天收件箱或永久输出区 |

### 中枢管理工具与元数据

以下是持续保留的管理工具和元数据，不是用完即删的一次性安装材料。

| 路径（相对工作区根） | 用途与是否保留 |
| --- | --- |
| [中枢/工具/工作区管理/工作区管理.py](中枢/工具/工作区管理/工作区管理.py) | 工作区管理程序，提供 `init` / `status` / `configure`；从自身未解析链接的绝对路径 `parents[3]` 定位工作区根并检查祖先链接，启用后仍需使用，保留 |
| [中枢/模板/模板信息.json](中枢/模板/模板信息.json) | 程序依赖的版本、`default_memory_mode` 等模板信息，不是可随意删的介绍文件 |
| `中枢/模板/出厂文件清单.json`（分发包内） | 不可重写的出厂来源基线与 SHA-256 清单，不是实时状态；保留出厂原值，不更新哈希冒充未改动原版 |

本文所有管理命令均从工作区根运行。移动管理程序与模板元数据不改变已有身份或模式：`中枢/启用状态.json`、`中枢/记忆/配置.json` 原位保留，不删除、不重置。

灵魂是可调整的中性底色，长期改变须明确要求；[记忆入口](中枢/记忆/记忆.md)初始无个人条目或种子，[客户端接入](中枢/接入/客户端接入.md)说明显式启动与真实验证边界。

**初始化后不自动删除任何文件。** 模板源码不含 `中枢/启用状态.json` 或 `中枢/记忆/配置.json`；`init` 生成前者的独立身份、版本、模式与启用依据，以及后者的六字段配置。它们是持续运行必需文件，不是临时文件，必须保留，不能删除以“重新初始化”；字段合同见[格式规范](中枢/记忆/格式规范.md)。普通记忆由 CLI 保存，派生索引与唯一生成链接区可重建。

`中枢/模板/出厂文件清单.json` 只比对出厂版本：启用后正常记忆入口重建或授权修改可能导致哈希变化，不一定是损坏，也不得为消除差异改写出厂来源基线。本包不提供旧副本自动迁移，不应直接覆盖已有工作区；客户端行为与长期使用验收仍需在实际环境中确认。

## 能力与安全边界

首版不安装 skills、MCP 或 hooks，不自动联网、不运行后台服务、不开全局配置，不自动初始化 Git、提交、推送或外发。文件链接不保证被客户端加载，不同步平台自身的记忆、聊天或账户。

记忆工具只依赖 Python 标准库，但**所有正常查询也需要可写运行锁**，不能把它当只读介质工具。缺工具时按记忆入口人工降级，不直接手改公共条目。文件规则和 manual/auto 模式都是协作约定，不是操作系统级隔离；交给远端模型处理的本地内容也可能进入相应服务。

资料、成果与记录围绕具体事项放置，中枢不收集全部个人档案。敏感内容按最小必要使用，公共记录不复制敏感正文或凭据；删除、覆盖、安装和外发另看当前明确授权。模板不继承作者的记忆、个人偏好、原操作授权或账户状态。

**许可证尚未选定。** 不因能够取得文件就推定已授予任意复用、修改或再分发的许可。
