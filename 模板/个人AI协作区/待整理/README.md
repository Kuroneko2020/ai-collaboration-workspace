# 待整理

这里只接收暂时无法合理归入已有主题的新事项，不是永久通用输出区，也不是每轮聊天的自动收件箱。先遵守[根 AGENTS](../AGENTS.md)与[工作区维护指南](../中枢/工作区维护指南.md)。

## 怎样放置

- 已有明确主题时直接归入该主题，不先绕到这里。
- 有实际任务但归属未定时，在工作区根的本目录下建立 `YYYY-MM-DD--简短主题/`，把同一事项的输入、成果与必要记录放在一起；不另建 `outputs`，不预造大量空目录。
- 最小记录说明目标与范围、输入来源、当前状态、变更位置、验证和未完成项。普通小任务可用已有说明；持续维护、含源码或成品、依赖外部输入或有独立边界的事项按维护指南建立 AGENTS。
- 原始下载、数据库、工作簿、配置、存档与聊天导出默认不可覆盖；修改前读取目标，候选另存，不为整理丢弃用户或其他 Agent 的改动。
- 确定长期归属后，在明确的整理范围内迁入相应主题并修正入口；移动、合并或重复文件不自动授予删除权限。不要为清空这里而清理未知文件、缓存或链接目标。

记录按具体事项保存，不复制凭据、敏感正文或无关第三方信息，不把整理变成全盘记忆提取。首次启用默认 auto，普通记忆只在当前模式及[记忆管理规则](../中枢/记忆/管理规则.md)允许的范围持续维护，无需逐条确认；已选择 manual 时仍须明确保存请求。整理资料不切换模式，也不扩大保存范围。

当前不预装作者任务或个人资料。长期主题的入口维护在[主题路由表](../中枢/主题路由表.md)，本文件不建立第二份总导航。
